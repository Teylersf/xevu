## Product description

XEVU is an open-source, offline file workspace for carrying encrypted documents
and media. Boot from supported USB/SD media or try the native preview in a VM.
Choose your source drives, keep encrypted copies in the vault, view supported
formats, and export original files when you decide they should leave.

## Feature copy

**Keep your originals.** Import files as encrypted objects with hidden names and
contents. Raw documents and videos do not need conversion for storage or export.

**Choose what moves.** Select drive access explicitly. Export restores the stored
original filename and exact unencrypted bytes, with readback verification.

**Carry your workspace.** Explore a native x86-64 UEFI environment from supported
USB/SD media, or test it with regular virtual disks in a VM.

**See how it works.** Public source, documented formats and published verification
evidence. No native network stack or telemetry is included.

## Preview notice for handouts and listings

XEVU is an unsigned, unaudited, firmware-backed engineering preview, not a
completed standalone OS. Use test data. Native viewers and filesystem support are
limited. Three failed native unlocks erase the boot medium. Native export uses a
writable removable FAT drive; C: output uses the Windows companion. Exported
plaintext, backups and clones remain independent copies. See README and SECURITY.

## Avoid

Do not claim "military grade," "unhackable," "untraceable," "quantum proof,"
"classified approved," "all formats play natively," "nothing can touch another
drive," "guaranteed flash sanitization," or "direct NTFS C: writes." Do not imply
that the new name represents new cryptography, compliance or a completed kernel.
